## 🎯 核心功能流程

### 声景播放流程
```
1. 地图/发现页面 → 点击墨点
2. 显示声景详情弹窗
3. 点击"播放声景"
4. 进入播放器页面
5. 全屏沉浸式播放体验
```

### 声景上传流程
```
1. 点击"+"按钮
2. 进入上传页面
3. 选择音频文件
4. 填写基本信息
5. 选择时期和情绪
6. 编写收尾诗
7. 提交上传
8. 等待审核
```

### 搜索筛选流程
```
1. 点击搜索图标
2. 进入搜索页面
3. 输入关键词
4. 选择时期筛选
5. 选择情绪筛选
6. 查看搜索结果
7. 点击查看详情
```
