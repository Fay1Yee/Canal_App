### 1. 水墨晕染效果（参考图片1）

#### InkPaintingBackground 组件

- **晕染位置**: 随机分布在屏幕不同位置，营造自然的水墨感
- **透明度控制**: 0.05-0.15 之间，保持背景的克制和优雅
- **模糊效果**: MaskFilter.blur 模拟水墨在宣纸上的渗透效果

## 🎯 核心设计原则

### 1. 对比与平衡
- **黑白对比**: 纯黑背景 + 纯白前景
- **虚实对比**: 水墨晕染 + 清晰文字
- **刚柔并济**: 几何线条 + 柔和墨迹

### 2. 层次与空间
- **多层叠加**: 背景层 + 网格层 + 内容层
- **Z轴深度**: 通过透明度和模糊营造空间感
- **留白艺术**: 充足的间距和呼吸感

### 3. 功能与美学
- **信息优先**: 数据清晰可读
- **美学点缀**: 水墨效果不喧宾夺主
- **交互流畅**: 保持 Nothing OS 的简洁交互

### 4. 文化与科技
- **传统元素**: 水墨、诗词、古典配色
- **现代语言**: 几何、数据图表、技术标注
- **和谐共存**: 东方美学与现代设计的完美融合

## 📱 响应式设计

### 尺寸规范
- **网格间距**: 40px
- **圆形图表**: 70-100px
- **墨点标记**: 40-60px
- **诗词行高**: 1.8倍
- **字母间距**: 0.5-2.0px

### 适配策略
- 使用 MediaQuery 获取屏幕尺寸
- 百分比布局确保适配
- 最小触摸区域 48x48dp

## 🚀 性能优化

### 渲染优化
- **CustomPainter 复用**: shouldRepaint 返回 false
- **透明度优化**: 避免过度透明度混合
- **图层管理**: 合理使用 RepaintBoundary

### 动画性能
- **硬件加速**: 使用 Transform 而非 Container
- **帧率控制**: 保持 60fps
- **动画曲线**: Curves.easeInOut 保证流畅

## 🎨 设计哲学

> "墨韵科技，声景传承"

在极简的黑白世界中，用水墨的柔和冲淡科技的冷硬，用几何的精确平衡水墨的飘逸，用数据的清晰传达文化的深度。

这不仅是一个声景应用，更是一次传统与现代的对话，一场视觉的诗意探索。
